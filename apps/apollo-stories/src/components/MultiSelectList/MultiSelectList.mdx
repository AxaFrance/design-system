# MultiSelectList

## Import

```tsx
import { MultiSelectList } from "@axa-fr/canopee-react/prospect";
```

## Uses

The `MultiSelectList` component displays a list of `ItemMultiSelect`
checkboxes. The items alternate between the `primary` and `secondary`
variants.

Each item requires an `id` and a `label`. Items also accept the native input
props of an HTML checkbox, such as `checked`, `disabled`, `name`,
`aria-*`, `className` and `onChange`. These item-level props allow the input
configuration to be customized for each option.

### Item type

```tsx
type MultiSelectListItem = Omit<
  React.ComponentProps<"input">,
  "type" | "id"
> & {
  id: string;
  label: React.ReactNode;
  variant?: "primary" | "secondary";
};

type MultiSelectListProps = {
  items: MultiSelectListItem[];
};
```

### MultiSelectList

```tsx
const items = [
  {
    id: "option-1",
    label: "Option 1",
    name: "options",
    "aria-label": "Select Option 1",
  },
  {
    id: "option-2",
    label: "Option 2",
    checked: true,
    disabled: false,
  },
];

<MultiSelectList items={items} />;
```
