# DataAgent

> **Warning:** The `texteOrias` prop is deprecated. Please use `oriasText` instead.

To use the DataAgent import it like that:

```tsx
import { DataAgent } from "@axa-fr/canopee-react/prospect";
import accountBalance from "@material-symbols/svg-400/rounded/account_balance-fill.svg";

const MyComponent = () => (
  <DataAgent
    agentContractProps={{
      subtitle: "Assurance Vie, Auto, Habitation, Complémentaire santé",
      title: "Contrat rattaché",
      type: "stick",
    }}
    agentProps={{
      picture: "https://dummyimage.com/48/48/fff&text=A",
      subtitle: "AXA Assurance & Banque",
      title: "Michel Lhote",
      type: "picture",
    }}
    aria-label="Votre conseiller"
    clickContents={[
      {
        icon: accountBalance,
        onClick: () => {},
        title: "Envoyer un message",
      },
      {
        icon: accountBalance,
        onClick: () => {},
        title: "Envoyer un message à l’agent",
      },
      {
        icon: accountBalance,
        onClick: () => {},
        title: "Accéder à plus d’informations",
      },
    ]}
    contents={[
      {
        iconProps: { src: accountBalance },
        subtitle1: "01 23 34 45 67",
        title: "",
        type: "icon",
      },
      {
        iconProps: { src: accountBalance },
```

## Contents and click items

`contents` and `clickContents` take one to three items each, as the mockup has three content slots
and three click slots (the second and third ones being optional).

Click items always use the `small` Click Item of the mockup: their `variant` is ignored.

## Compact

Use `variant="compact"` to force the compact layout (header only — avatar + name + subtitle) regardless of screen size.
This is useful when the DataAgent is embedded in a constrained layout such as a desktop sidebar.

The compact layout shows a single Click Item built from `agentProps`. Pass an `onClick` in
`compactClickItemProps` to make it interactive.

```tsx
<DataAgent
  agentProps={{
    picture: "https://dummyimage.com/48/48/fff&text=A",
    subtitle: "AXA Assurance & Banque",
    title: "Michel Lhote",
    type: "picture",
  }}
  compactClickItemProps={{ onClick: () => {} }}
  variant="compact"
/>
```

## Accessibility

The DataAgent renders a `section`. Name it with `aria-label` or `aria-labelledby` (for example
the id of the heading displayed above it) so that screen readers list it as a region. The
contents and the click items are rendered as lists.
