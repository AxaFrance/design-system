# Card

The **Card** component is a simple wrapper that adds **padding and a border**.
Use the `as` prop to control the underlying HTML element.

## Import

```tsx
import { Card, Heading } from "@axa-fr/canopee-react/prospect";
```

## Usage

```tsx
// Basic card
<Card>
  <Heading level={2} className="af-card__title">My card title</Heading>
  <p>My card content</p>
</Card>

// Clickable card rendered as a button
<Card as="button" type="button" onClick={handleClick}>
  <Heading level={2} className="af-card__title">My card title</Heading>
  <p>My card content</p>
</Card>

// Unstyled variant (removes border and padding)
<Card variant="unstyled">
  <p>My card content</p>
</Card>
```
