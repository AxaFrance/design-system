# Header

Responsive page header, in two styles as in the mockup:

- **Default**: AXA logo, an optional `TabMenu`, optional action children (a secondary button) and an optional `MenuBurger` (the primary button).
- **Parcours**: AXA logo and a `title`, at the end of the header, in place of the actions.

The same elements serve both screen sizes; CSS lays them out. On desktop (1024px and more), everything is on one line; the `MenuBurger` panel uses the native [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API), with a veil on the page: blue-1000 at 40% in the prospect look, gray-1000 at 48% in the client look. On mobile (up to 1023px), the header shows the logo, the title and a "Menu" button. The button opens the menu, a native popover under the header; a close button takes the place of the "Menu" button. The menu shows the `TabMenu` items as links, a divider, the `MenuBurger` click items, then, at the bottom, the action children and the `MenuBurger` children.

## Accessibility

- One `<header>` and one `<nav>`, the `TabMenu`, on every screen size. Give it a name with `aria-label` when the page has several navigations.
- The "Menu" button opens the menu with the native Popover API (`popovertarget`): browsers give its expanded state to assistive technologies. It points to the menu with `aria-controls`. Its name does not change; pass `clickIconProps={{ "aria-label": "…" }}` to change it. At 32px, it meets the minimum target size of WCAG 2.2 (2.5.8, 24px).
- The menu is not modal. The browser closes it with Escape, the close button ("Fermer le menu", see `closeButtonAriaLabel`) or a click outside of it, and gives the focus back to the "Menu" button. Choosing a link or a `MenuBurger` entry, or moving the focus out of the menu to the page, closes it too. The close button comes right after the "Menu" button in the focus order; when it covers that button, it shows its focus. The page does not scroll while the menu is open.
- On mobile, CSS puts the action children after the `MenuBurger` click items; browsers that support `reading-flow` follow that order with the keyboard.

## Import

```tsx
import { Header } from "@axa-fr/canopee-react/client";
```

## Usage

```tsx
import {
  Header,
  Button,
  Icon,
  type HeaderProps,
  type MenuBurgerProps,
} from "@axa-fr/canopee-react/client";
import logout from "@material-symbols/svg-400/rounded/logout.svg";
import settings from "@material-symbols/svg-400/rounded/settings-fill.svg";

const tabMenuProps: HeaderProps["tabMenuProps"] = {
  items: [
    { href: "/", label: "Accueil", isActive: true },
    { href: "/contrats", label: "Contrats" },
  ],
};

const menuBurgerProps: MenuBurgerProps = {
  buttonLabel: "Mon espace",
  clickItems: [
    {
      icon: settings,
      title: "Mon profil",
      subtitle: "Informations personnelles",
      state: "default",
      ariaLabelForActionIcon: "Aller à mon profil",
      onClick: () => {},
    },
  ],
  children: (
    <Button
      variant="tertiary"
      iconLeft={<Icon src={logout} size="S" />}
      onClick={() => {}}
    >
      Déconnexion
    </Button>
  ),
};

<Header
  appNameProps={{ logoLinkProps: { href: "/" } }}
  tabMenuProps={tabMenuProps}
  menuBurgerProps={menuBurgerProps}
/>;
```

## Props

| Prop                   | Type              | Default            | Description                                                                                                  |
| ---------------------- | ----------------- | ------------------ | ------------------------------------------------------------------------------------------------------------ |
| `appNameProps`         | `AppNameProps`    | —                  | AXA logo (`logoLinkProps`, `logoAlt`). **Required.** `label` is deprecated: the mockup shows the logo alone. |
| `tabMenuProps`         | `TabMenuProps`    | `undefined`        | Navigation items: tabs on desktop, links at the top of the mobile menu.                                      |
| `menuBurgerProps`      | `MenuBurgerProps` | `undefined`        | Account menu rendered as a burger button on desktop.                                                         |
| `clickIconProps`       | `ClickIconProps`  | `undefined`        | Props forwarded to the mobile "Menu" button.                                                                 |
| `closeButtonAriaLabel` | `string`          | `"Fermer le menu"` | Accessible name of the close button of the mobile menu.                                                      |
| `title`                | `string`          | `undefined`        | Title displayed at the end of the header ("Parcours" style).                                                 |
| `actionChildren`       | `ReactNode`       | `undefined`        | Free content rendered in the actions zone (e.g. a CTA button).                                               |
| `className`            | `string`          | `undefined`        | Additional CSS class on the `<header>` element.                                                              |
