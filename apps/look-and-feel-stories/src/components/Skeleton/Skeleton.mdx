# Skeleton

To use the Skeleton import it like that:

```tsx
import { Skeleton } from "@axa-fr/canopee-react/client";

const MyComponent = () => <Skeleton colSize={6} rowSize={1} />;
```

## Props

Use `colSize` to set the column span and `rowSize` to set the row span.
