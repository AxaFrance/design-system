# DropdownMultiSelect

## Import

```tsx
import { DropdownMultiSelect } from "@axa-fr/canopee-react/client";
```

## Uses

The `DropdownMultiSelect` component displays a dropdown containing a list of
checkboxes. Selected options are summarized in the trigger and displayed as
tags below it.

The component accepts an array of `items`. Each item must have an `id` and a
`label`. An item can be initially selected with `checked: true`.

The component is always **uncontrolled**: it manages its own selection state
internally, and clicking an item always updates it, so it works inside a
plain `<form>` without any extra wiring. `defaultValue` can be used to seed
the initial selected IDs. When it is not provided, the initial selection is
inferred from the items whose `checked` property is `true`. Changing
`defaultValue` after the initial render has no effect, exactly like a native
`<input defaultValue>`.

`onChange` is called with the native change event of the checkbox that was
selected or deselected. The selected ID is available through
`event.target.value` and the new state through `event.target.checked`.

`hideThreshold` controls how many selected tags remain visible below the
dropdown. Additional tags are grouped into an overflow tag showing the number
of hidden selections.

### DropdownMultiSelect

```tsx
import { DropdownMultiSelect } from "@axa-fr/canopee-react/client";

export const DropdownMultiSelectComponent = () => (
  <DropdownMultiSelect
    label="Choix multiples"
    helper="Sélectionnez une ou plusieurs options"
    items={[
      { id: "option-1", label: "Option 1" },
      { id: "option-2", label: "Option 2" },
      { id: "option-3", label: "Option 3" },
    ]}
    defaultValue={["option-1"]}
    hideThreshold={2}
    onChange={(event) => {
      console.log(event.target.value, event.target.checked);
    }}
  />
);
```
