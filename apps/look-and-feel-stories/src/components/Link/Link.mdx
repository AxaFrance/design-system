## Link

### Import

```tsx
import { Link } from "@axa-fr/canopee-react/client";
```

### Use

```tsx
export const LinkComponent = () => (
  <Link openInNewTab href="https://fakelink.com">
    Plus de détails
  </Link>
);
```

## Accessibility

With `openInNewTab`, the name of the link ends with a visually hidden `(nouvelle fenêtre)`
and the icon stays decorative. The optional `newWindowLabel` prop changes the text in
parentheses.
