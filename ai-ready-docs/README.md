# Documentation design de Canopée

Canopée est le design system d'AXA. Les designers, les développeurs et les agents IA trouvent ici comment l'utiliser.

| Dossier | Contenu |
|---|---|
| [Fondations](fondations/) | Les design tokens, et comment l'équipe design system les crée et les modifie. |
| [Règles](regles/) | Les règles communes à tout le design system, comme la nomenclature des composants, de leurs propriétés et de leurs calques. |
| [Assets](assets/) | Les icônes, les pictogrammes, les logos et les drapeaux de la librairie Figma Fondations Canopée, exportés en SVG. |
| [B2C](b2c/) | Les fiches des composants déjà documentés, et les templates de page, de section et de bloc. |
| [Plugins Figma](plugins-figma/) | Les plugins Figma de Canopée, pour exporter les design tokens et les composants, et leur mode d'emploi. |
| [Skills](skills/) | Les consignes que suivent les agents IA de l'équipe design system pour documenter et auditer Canopée. Aucune n'est encore écrite. |

Les composants et les templates du B2B ne sont pas encore traités ici.
