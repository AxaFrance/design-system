Déposer sur GitHub

Avant de déposerVérifier que Fondations est publiée et que l'équipe design system a validé les changements.

  1. Copier le fichier et ouvrir GitHub

  2. Sur GitHub, remplacer tout le contenu du fichier avec Cmd+A puis Cmd+V (Ctrl sur Windows). Cliquer ensuite sur « Commit changes ».
  3. Copier le message de commit

    Le coller dans GitHub, garder « Create a new branch », puis cliquer sur « Propose changes ».

  4. Cliquer sur « Create pull request ».
