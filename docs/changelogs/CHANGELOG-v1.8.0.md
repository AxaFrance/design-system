# Changelog v1.8.0

## 📋 Overview
Version 1.8.0 brings significant new components and variants across all universes. The Distributor universe gains a new Timeline component, an ExperimentalRestitution component, and several UI refinements. The Client/Prospect universe receives new components (RadioText, MultiMessage), warning variants for Dropdown and TextArea, and convergence improvements for ContentItemMono.
